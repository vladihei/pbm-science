# Historical WHO ICTRP analysis

This directory preserves the October 2026 ICTRP export analysis and search-coverage comparison. It is not the source of the `/studies/` website snapshot. For monthly publication work, use [`../direct-sources/MONTHLY-UPDATE.md`](../direct-sources/MONTHLY-UPDATE.md).

## Historical exercise

The 1 October 2026 exercise processed three supplied WHO ICTRP exports with 2,428 rows and 2,235 distinct registry IDs. This work identified likely high-yield provider registries and supplied a stratified keyword-relevance audit. These counts describe those files only, not current direct coverage or all PBM studies.

The ICTRP processing date was not included in the supplied export. The audit found 37 in scope, 9 unresolved, and 4 out of scope among 50 checked records. That audit does not validate the changed direct-source collection or any individual record's current status.

## Use and rights status

WHO ICTRP exports are not included in the website data. Only search strategy and provider-level counts are retained in the current branch for query design and ID-level coverage comparisons; the former record-level quality sample, decisions file and pilot output report have been removed from the review branch.

The supplied ICTRP files are also subject to the ICTRP terms and lack the processing date needed for publication under those terms. Do not use them as a redistributable feed. See `source-feasibility-2026-10-01.md` for the historical assessment and `../direct-sources/source-feasibility-2026-10-02.md` for the revised plan.
